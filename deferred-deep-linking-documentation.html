Deferred Deep Linking
with LinkTrace

Route newly installed users to any screen inside your app — even before the app exists on their device.

What is Deferred Deep Linking?

A standard deep link (e.g. myapp://promo/SAVE20) works only if the app is already installed. Tap the same link on a device without the app and it does nothing useful.

Deferred deep linking bridges this gap. A user taps a link, gets sent to the App Store or Play Store, installs your app, opens it for the first time — and still lands on the exact screen the link was pointing to. The "deferred" part means the navigation intent survives the install gap.

LinkTrace implements this through device fingerprint matching combined with the customPayload field. You encode a screenName (and any extra context) into the link at creation time. On first launch after sign-up, your app calls the Attribution API — if the install is matched, the original payload is returned and you navigate accordingly.

2 — Attribution Service

A lightweight async function that calls the Attribution API. Call this from your ViewModel or AppDelegate after sign-up.

Swift AttributionService.swift 
final class AttributionService {

    private let apiKey  = "YOUR_API_KEY"
    private let baseURL = "https://api.linktrace.in"

    func fetchAttribution(userId: String) async throws -> AttributionData {
        guard let url = URL(string: "\(baseURL)/api/v1/attributions") else {
            throw URLError(.badURL)
        }

        var request = URLRequest(url: url)
        request.httpMethod          = "POST"
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")
        request.setValue(apiKey,           forHTTPHeaderField: "x-api-key")
        request.httpBody = try JSONEncoder().encode(["userId": userId])

        let (data, _) = try await URLSession.shared.data(for: request)
        let response  = try JSONDecoder().decode(AttributionResponse.self, from: data)
        return response.data
    }
}

3 — Navigation via NavigationStack

Use a typed route enum with NavigationStack and a navigationPath. Call checkDeferredDeepLink from the .onAppear of your post-signup root view, or directly from your sign-up completion handler.

Swift AppRouter.swift 
// 1. Define your app's navigable routes
enum AppRoute: Hashable {
    case promoScreen(promoCode: String?)
    case onboardingVariantB
    case productDetail(id: String)
    case challengeInvite
    case referralSuccess(referrerName: String?)
    // add more routes as needed
}

// 2. Root view owning the NavigationStack
struct RootView: View {
    @StateObject private var router = AppRouter()

    var body: some View {
        NavigationStack(path: $router.path) {
            HomeView()
                .navigationDestination(for: AppRoute.self) { route in
                    switch route {
                    case .promoScreen(let code):
                        PromoView(promoCode: code)
                    case .onboardingVariantB:
                        OnboardingVariantBView()
                    case .productDetail(let id):
                        ProductDetailView(productId: id)
                    case .challengeInvite:
                        ChallengeInviteView()
                    case .referralSuccess(let name):
                        ReferralSuccessView(referrerName: name)
                    }
                }
        }
        .environmentObject(router)
    }
}

// 3. Router class — holds path and resolution logic
@MainActor
final class AppRouter: ObservableObject {

    @Published var path = NavigationPath()

    private let service  = AttributionService()
    private let defaults = UserDefaults.standard

    func checkDeferredDeepLink(userId: String) {
        // Guard: only run once per user
        guard !defaults.bool(forKey: "lt_attribution_checked") else { return }

        Task {
            do {
                let data = try await service.fetchAttribution(userId: userId)
                defaults.set(true, forKey: "lt_attribution_checked")

                guard data.attributed,
                      let payload    = data.customPayload,
                      let screenName = payload["screenName"] else { return }

                navigate(to: screenName, payload: payload)
            } catch {
                // Attribution failure is non-fatal; continue default flow
            }
        }
    }

    private func navigate(to screenName: String, payload: [String: String]) {
        switch screenName {
        case "promo_screen":
            path.append(AppRoute.promoScreen(promoCode: payload["promoCode"]))
        case "onboarding_variant_b":
            path.append(AppRoute.onboardingVariantB)
        case "product_detail":
            guard let id = payload["productId"] else { return }
            path.append(AppRoute.productDetail(id: id))
        case "challenge_invite":
            path.append(AppRoute.challengeInvite)
        case "referral_success":
            path.append(AppRoute.referralSuccess(referrerName: nil))
        default:
            break
        }
    }
}

4 — Trigger After Sign-Up

Inject the router into your sign-up view and call checkDeferredDeepLink as soon as the user's account is created.

Swift SignUpView.swift 
struct SignUpView: View {
    @EnvironmentObject private var router: AppRouter
    @State private var isLoading = false

    var body: some View {
        VStack {
            // ... sign-up form UI ...

            Button("Create Account") {
                Task { await handleSignUp() }
            }
        }
    }

    private func handleSignUp() async {
        isLoading = true
        defer { isLoading = false }

        // 1. Create the user account in your backend
        let userId = try await AuthService.signUp(...)

        // 2. Check for a deferred deep link — navigates if attributed
        router.checkDeferredDeepLink(userId: userId)
    }
}

interface LinkTraceApi {
    @POST("/api/v1/attributions")
    @Headers("x-api-key: YOUR_API_KEY")
    suspend fun fetchAttribution(
        @Body body: Map<String, String>
    ): AttributionResponse
}

class AttributionRepository(private val api: LinkTraceApi) {

    suspend fun fetchAttribution(userId: String): Result<AttributionData> =
        runCatching { api.fetchAttribution(mapOf("userId" to userId)).data }
}

3 — ViewModel

Expose a SharedFlow event so the Fragment/Activity can react to navigation without coupling to the NavController.

Kotlin SignUpViewModel.kt 
sealed class DeepLinkDestination {
    data class PromoScreen(val promoCode: String?): DeepLinkDestination()
    object     OnboardingVariantB:                   DeepLinkDestination()
    data class ProductDetail(val productId: String):  DeepLinkDestination()
    object     ChallengeInvite:                      DeepLinkDestination()
}

class SignUpViewModel(private val repo: AttributionRepository) : ViewModel() {

    private val _deepLink = MutableSharedFlow<DeepLinkDestination>()
    val deepLink: SharedFlow<DeepLinkDestination> = _deepLink.asSharedFlow()

    private val prefs = /* inject SharedPreferences */

    fun checkDeferredDeepLink(userId: String) {
        if (prefs.getBoolean("lt_attribution_checked", false)) return

        viewModelScope.launch {
            repo.fetchAttribution(userId)
                .onSuccess { data ->
                    prefs.edit().putBoolean("lt_attribution_checked", true).apply()
                    if (!data.attributed) return@onSuccess
                    val payload    = data.customPayload ?: return@onSuccess
                    val screenName = payload["screenName"] ?: return@onSuccess
                    resolveDestination(screenName, payload)?.let { _deepLink.emit(it) }
                }
        }
    }

    private fun resolveDestination(
        screenName: String,
        payload: Map<String, String>
    ): DeepLinkDestination? = when (screenName) {
        "promo_screen"         -> DeepLinkDestination.PromoScreen(payload["promoCode"])
        "onboarding_variant_b" -> DeepLinkDestination.OnboardingVariantB
        "product_detail"       -> payload["productId"]?.let { DeepLinkDestination.ProductDetail(it) }
        "challenge_invite"     -> DeepLinkDestination.ChallengeInvite
        else                   -> null
    }
}

4 — Fragment — Collect & Navigate

Observe the deepLink flow in your post-signup Fragment and navigate using the Jetpack NavController.

Kotlin SignUpFragment.kt 
class SignUpFragment : Fragment() {

    private val viewModel: SignUpViewModel by viewModels()

    override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
        super.onViewCreated(view, savedInstanceState)

        // Observe deep link navigation events
        viewLifecycleOwner.lifecycleScope.launch {
            repeatOnLifecycle(Lifecycle.State.STARTED) {
                viewModel.deepLink.collect { destination ->
                    navigateTo(destination)
                }
            }
        }

        // Sign-up button
        binding.btnCreateAccount.setOnClickListener {
            lifecycleScope.launch {
                val userId = performSignUp()   // your auth call
                viewModel.checkDeferredDeepLink(userId)
            }
        }
    }

    private fun navigateTo(destination: DeepLinkDestination) {
        val navController = findNavController()
        when (destination) {
            is DeepLinkDestination.PromoScreen -> {
                val args = PromoFragmentArgs(promoCode = destination.promoCode)
                navController.navigate(R.id.action_signUp_to_promo, args.toBundle())
            }
            DeepLinkDestination.OnboardingVariantB ->
                navController.navigate(R.id.action_signUp_to_onboardingB)
            is DeepLinkDestination.ProductDetail -> {
                val args = ProductDetailFragmentArgs(productId = destination.productId)
                navController.navigate(R.id.action_signUp_to_productDetail, args.toBundle())
            }
            DeepLinkDestination.ChallengeInvite ->
                navController.navigate(R.id.action_signUp_to_challenge)
        }
    }
}

2 — DeepLinkHandler Utility

A standalone object that builds and fires the correct Intent from the attribution data. No nav graph required.

Kotlin DeepLinkHandler.kt 
object DeepLinkHandler {

    // Intent extras keys — keep in sync with target Activities
    const val EXTRA_PROMO_CODE  = "extra_promo_code"
    const val EXTRA_PRODUCT_ID  = "extra_product_id"

    fun handle(context: Context, data: AttributionData): Boolean {
        if (!data.attributed) return false

        val payload    = data.customPayload ?: return false
        val screenName = payload["screenName"] ?: return false

        val intent = buildIntent(context, screenName, payload) ?: return false
        // Clear the sign-up stack so Back doesn't return to it
        intent.addFlags(Intent.FLAG_ACTIVITY_CLEAR_TOP or Intent.FLAG_ACTIVITY_NEW_TASK)
        context.startActivity(intent)
        return true
    }

    private fun buildIntent(
        context: Context,
        screenName: String,
        payload: Map<String, String>
    ): Intent? = when (screenName) {
        "promo_screen" ->
            Intent(context, PromoActivity::class.java).apply {
                putExtra(EXTRA_PROMO_CODE, payload["promoCode"])
            }
        "onboarding_variant_b" ->
            Intent(context, OnboardingVariantBActivity::class.java)
        "product_detail" ->
            payload["productId"]?.let { id ->
                Intent(context, ProductDetailActivity::class.java).apply {
                    putExtra(EXTRA_PRODUCT_ID, id)
                }
            }
        "challenge_invite" ->
            Intent(context, ChallengeActivity::class.java)
        else -> null
    }
}

3 — Trigger From SignUpActivity

After your auth call succeeds, fetch attribution and pass the result to DeepLinkHandler.

Kotlin SignUpActivity.kt 
class SignUpActivity : AppCompatActivity() {

    private val repo  = AttributionRepository(/* inject */)
    private val prefs by lazy { getSharedPreferences("lt_prefs", Context.MODE_PRIVATE) }

    private fun onSignUpSuccess(userId: String) {
        if (prefs.getBoolean("lt_attribution_checked", false)) {
            goToHome()
            return
        }

        lifecycleScope.launch {
            repo.fetchAttribution(userId)
                .onSuccess { data ->
                    prefs.edit().putBoolean("lt_attribution_checked", true).apply()
                    val handled = DeepLinkHandler.handle(this@SignUpActivity, data)
                    if (!handled) goToHome()
                }
                .onFailure { goToHome() }  // attribution failure is non-fatal
        }
    }

    private fun goToHome() {
        startActivity(Intent(this, HomeActivity::class.java))
        finish()
    }
}

Best Practices
🔁
Gate behind a one-time flag Persist a hasCheckedAttribution boolean in local storage. Check it before calling the Attribution API — this prevents duplicate calls on subsequent launches.
🛡️
Always handle attributed: false Attribution failure or no-match is the common case for organic installs. Your app must have a clean default post-signup flow that runs when no deep link is present.
📦
Keep screenName values in a shared constant Define screen name strings in a single file (e.g. DeepLinkScreens.kt / DeepLinkRoutes.swift) shared between link creation and navigation logic to avoid typo mismatches.
🧪
Test with environment: "stage" Always create test links with "environment": "stage" to validate the full deferred deep linking flow end-to-end without polluting production attribution data.
⏰
Attribution window is 24 hours The user must install within 24 hours of clicking the link. If the window expires, the Attribution API returns attributed: false — your default flow takes over. Set expectations accordingly in QA.
🔤
customPayload values must be strings All values in customPayload are strings. For numeric IDs or booleans, stringify on encode and parse on receipt (e.g. "productId": "42", not "productId": 42).

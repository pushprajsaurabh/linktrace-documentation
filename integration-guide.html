LinkTrace Developer Docs

Link Generation → Attribution
Integration Flow

Complete lifecycle for a developer integrating LinkTrace — from creating your first link to receiving attribution data on install.

01
Create the Link
Via the LinkTrace dashboard manually, or programmatically through the API from your server
Dashboard / API
API Request
HTTP POST 
POST https://api.linktrace.in/api/v1/referral-links
x-api-key: YOUR_API_KEY

{
  "referrerIdentifier": "user_9821",   // required
  "source":             "home_tab",
  "campaign":           "summer_referral",
  "medium":             "social",
  "environment":        "production",
  "customPayload": {
    "cta":  "friend_invite_popup",
    "date": "Apr 2026"
  }
}
Response
JSON 201 Created 
{
  "success": true,
  "data": {
    "shortCode": "56ff9241",
    "referralLink":
      "https://app.linktrace.in/r/56ff9241",
    "referrerIdentifier": "user_9821",
    "source": "home_tab",
    "campaign": "summer_referral",
    "environment": "production"
  }
}
Parameters
referrerIdentifier REQUIRED Who gets credit — your user ID, partner ID, or any stable string. This is what you get back on attribution.
source OPTIONAL Where the link will be shared — e.g. "home_tab", "email", "twitter"
campaign OPTIONAL The campaign name — e.g. "summer_referral_2025", "launch_week"
medium OPTIONAL Marketing medium — e.g. "social", "email", "cpc"
environment OPTIONAL "production" (default) or "stage" for sandbox testing without polluting prod data
customPayload OPTIONAL Up to 3 key-value string pairs. Returned verbatim on attribution — use for promo codes, CTA context, or onboarding variants.
save the short link

03
LinkTrace Records the Click & Redirects
Happens automatically — no code needed from you
Auto / LinkTrace
①
Logs the click against shortcode 56ff9241
②
Captures a device fingerprint to enable later matching
③
Detects platform from user-agent — iOS or Android
④
Redirects user to → App Store (iOS) or Play Store (Android)
⏰  Attribution window starts NOW — install must happen within  24 hours
user downloads & installs the app
04
Call the Attribution API
Call this once — on first launch or after sign-up is complete
Your Mobile App
API Request
HTTP POST 
POST https://api.linktrace.in/api/v1/attributions
x-api-key: YOUR_API_KEY

{
  "userId":    "your_internal_user_id", // required
}
Parameters
userId REQUIRED Your internal user or device ID. Must be stable and consistent — never a session token or temporary value.
⚠️ IMPORTANT
Call this once per user — on first launch or right after sign-up. Not on every app open.
LinkTrace matches device fingerprint to recorded click
05
Attribution Result
Deterministic matching — device fingerprint from click vs. install
Auto / LinkTrace
Two possible outcomes:
✓ Attributed
"attributed": true
"referrerIdentifier": "user_9821"
"source": "home_tab"
"campaign": "summer_referral"
"medium": "social"
"customPayload": { cta, date, ... }
All parameters set at link creation are returned verbatim. Use them to credit the referrer, trigger rewards, or personalise onboarding.
✗ Not Attributed
"attributed": false
User installed organically, or the install happened outside the 24-hour attribution window after the click. No link data returned.
What to do with attributed: true
  • 💰 Credit the referrer (referrerIdentifier)
  • 🎁 Trigger referral reward / bonus
  • 📊 Segment users by source & campaign
  • 🎯 Personalise onboarding with customPayload
  • 🏷️ Apply promo code from customPayload

Integration Rules
🔁
Call attribution once per user On first launch or after sign-up — not on every app open. Duplicate calls may cause unexpected results.
🆔
userId must be stable Use your internal user ID or a persistent device ID — never a session token, temp ID, or anything that rotates.
⏰
24-hour attribution window The user must install within 24 hours of clicking the link. Installs outside this window return attributed: false.
🧪
Use environment: "stage" for testing Test the full flow end-to-end without polluting your production analytics or attribution counts.
📦
customPayload is returned verbatim This is optional. Anything you set at link creation (promo codes, CTA labels, tiers) comes back on attribution — this can be used to drive onboarding logic.
